# Unsubscribed - never contact

Everyone who has asked not to be contacted by «company».

**Check every recipient list against this file before a mailing goes out.** An
opted-out contact receiving another mailing is the one CRM mistake that cannot be
corrected afterwards.

Rows are **never** removed. The list is permanent - that is its entire function.
An empty list means nobody has asked, not that the file should be tidied.
